# Java Piscine - Intensive Problem Solving

This repository contains my solutions for a rigorous 3-week Java "Piscine" (intensive coding bootcamp). It includes over 60 algorithmic and architectural challenges that I completed to master Java fundamentals, Object-Oriented Programming, and modern Java features.

## 🧠 Key Areas Covered

### 🏗️ Object-Oriented Programming (OOP)
- **Inheritance & Polymorphism:** `StarInheritance`, `StarOverride`, `AdventureAbstract`, `AdventureInterface`
- **Encapsulation & Properties:** `StarGetters`, `StarProperties`, `StarStatic`

### 📐 Design Patterns (GoF)
- `Singleton`, `Factory`, `Builder`, `Strategy`, `Observer`, `Decorator`

### 🌊 Java Streams & Collections
- **Streams API:** `StreamMap`, `StreamReduce`, `StreamCollect`
- **Data Structures:** Lists (`ListContains`, `SortList`), Maps (`MapEquals`, `MapInventory`), Sets (`SetEquals`, `SetOperations`)

### ⚙️ Core Java & Algorithms
- **String Manipulation:** `StringReplace`, `RegexMatch`, `Palindrome`, `Capitalize`
- **File I/O:** `FileManager`, `FileSearch`, `CatInFile`
- **Date & Time:** `FormatDate`, `ParseDate`, `DifferenceBetweenDate`
- **Exception Handling:** `AdventureException`

All exercises were solved independently with a strong focus on clean code, memory efficiency, and strict edge-case handling.
